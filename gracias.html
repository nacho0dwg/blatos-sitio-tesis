Pasala

Si conocés a alguien de Cosquín o de la zona a quien le pueda interesar —sobre todo adultos mayores, o familias que conviven entre varias generaciones— compartirle la encuesta suma muchísimo.

Si esa persona necesita ayuda para completarla, se puede responder de forma asistida: la encuesta tiene una opción para indicarlo, y eso queda registrado como parte del dato.

El link para compartir es esta misma página de inicio: desde ahí se llega a la encuesta y también a los resultados.
